# Proposal

## Why

Users need to know how to link Google Drive (including Google's "unverified app" warning) and how to get and
refresh the Goodreads export file.

## What Changes

- A Help page, linked from the sidebar, with topics: adding books, linking Google Drive, importing from Goodreads,
  making text larger; a list of topic links at the top.

## Capabilities

### New Capabilities

- `help`: the in-app Help page.

### Modified Capabilities

## Impact

New `HelpPage.razor`, a sidebar link and styles.
